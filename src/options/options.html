Sidebar AI settings

Appearance

Theme How the side panel is lit. System follows whatever your computer is set to, including switching with it at dusk; the other two hold regardless. This is the panel only — the provider's own page keeps its own theme, which is set in that provider's account.
Accent colour The colour used for the send button, links, the provider pill and anything the panel wants you to notice. Each one is a pair — a darker shade for light mode and a lighter one for dark — because a single colour that reads correctly on white is close to invisible on a dark surface. Every pair is checked to stay legible against the surface it lands on.

Behaviour

How each provider is asked No popup asks the provider over its own API — nothing opens, nothing loads, and the reply arrives several times faster. Popup drives the page in a window, the way every other provider is driven. Set per provider because they do not break together: an engine can stop working for one while the other three are perfect.
ChatGPT and Gemini are on No popup out of the box, because their engines carry pictures and documents as well as text — so a chat never has to change transport partway through, and an agent run gets the speed-up too. Claude and Meta AI start on Popup: they can answer text this way, but the first attachment sends the conversation to a window and keeps it there. Switch them on here if you want the speed on text-only chats.
Only these four can avoid the popup at all. A provider set to No popup that cannot answer that way falls back to the window on its own rather than failing — press Check now to see which are actually working, and why not.
Page border while the agent drives The mark around the edge of a page the agent has taken control of — the one indicator that is visible wherever you happen to be looking. They differ in how much they move, which is the real choice: the ones that travel are found by the eye immediately and are also the first thing to look wrong in a screen recording. Each preview below runs the actual animation. Turning Show what the agent is doing off removes the border entirely, whichever is picked here.
Agent pointer The pointer drawn on the page as the agent moves and clicks. This is contrast, not taste: a light pointer disappears on a white form and a dark one disappears on a dark dashboard, and a pointer you cannot see says nothing about what just happened. Each is shown below on both grounds — pick the one you can still see on the sites you actually automate.

Providers & selectors

These sites change their markup without warning. When a provider stops responding, open it with Provider window → Visible, inspect the element in DevTools, and put a working CSS selector at the top of the matching list below — one selector per line, tried in order. Leave a list untouched to keep the shipped defaults.
